# CUVETSMO Labs

Umbrella index for experimental projects by Chula Vet students.

Live: https://labs.cuvetsmo.com

## Add a new lab

1. Edit `lib/labs.ts` — append to `LABS`.
2. (Optional) Bump `app/sitemap.ts` if there's an on-domain page.
3. Update `public/og.png` if the lineup changes meaningfully.
4. Push to `main` — Vercel auto-deploys.

## Stack

Next.js 16 App Router · TypeScript · Tailwind 4 · IBM Plex Sans Thai.

## Dev

```
npm install
npm run dev
```
